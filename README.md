# Gacha Audit Dashboard

Dashboard để audit và phát hiện gian lận trong hệ thống Gacha.

## Tính năng:
- Tra cứu thông tin user
- Xem kho thẻ và lịch sử gacha
- Thống kê server
- Phát hiện gian lận

## Files cần thiết:
- `analytics_dashboard.py` - Dashboard chính
- `gacha_card.csv` - Danh sách thẻ
- `gacha_history.csv` - Lịch sử gacha
- `user_card_inventory.csv` - Kho thẻ user
- `user_profile.csv` - Thông tin user

## Deployment:
Deploy trên Streamlit Cloud
